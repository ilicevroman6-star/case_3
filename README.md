Инструкция по использованию:
1. Запуск программы
   - Запустите файл main.py
   - Откроется консоль и графическое окно Turtle
   - В консоли появится меню
2. Главное меню
   - Введите номер пункта и нажмите Enter
   - Чтобы выйти — введите 10
   - Дракон находится в разработке
3. Ввод параметров
При выборе фрактала программа запрашивает:

- Глубина рекурсии — целое число (рекомендуется 3–8)
- Длина стороны — число (рекомендуется 100–300, для кривой Леви 1000)
- Угол (только для пункта 1) — угол в градусах

Особенности
- После отрисовки каждого фрактала окно автоматически очищается. 
- Пункт 9 (Дракон) выводит сообщение «Дракон сегодня заболел» и не рисует фрактал. 
- Программа защищена от некорректного ввода (пустые строки, буквы, выход за границы). 
- При закрытии окна Turtle программа корректно завершается.
